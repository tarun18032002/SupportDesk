# ShopLite - Returns Policy


Customers may request a change-of-mind return within 30 calendar days after delivery. The delivery date, not the order date, starts this window. Products must be unused, in their original packaging, and accompanied by proof of purchase. An unopened pair of headphones delivered 20 days ago is eligible if these conditions are met.

Opened personal-care products, downloaded digital products, and personalized items are not eligible for change-of-mind returns. Opened headphones that have been used and are not faulty are also not eligible. A change-of-mind request made 45 days after delivery is outside the return window.

Start a return from the Returns section of your ShopLite account. Approval is required before sending an item. For an approved change-of-mind return, the customer pays return shipping. Refund timing is described in the Refunds Policy.

An item that arrived damaged follows the separate Damaged Items Policy, even if its packaging has been opened. Do not apply the unused-item condition to an arrival-damage claim. The assistant cannot approve a return or access a customer's order.
